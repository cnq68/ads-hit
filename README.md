# ads-hit

Skill Claude Code để lên ads Meta cho Goodnight.

## Cài đặt

Clone repo rồi copy thư mục `ads-hit` vào `~/.claude/skills/`:

    git clone <repo-url>
    xcopy /E /I ads-hit "%USERPROFILE%\.claude\skills\ads-hit"

## Chỉnh sửa

Tạo nhánh, sửa `ads-hit/SKILL.md`, mở Pull Request. Không push thẳng vào `main`.
